## 清单

### 1. ONTR 冻结 / 换主干（2 份）

| 文件 | 一句话结论 |
|---|---|
| `DAYTIME_ONTR_REPORT.md` | 三条 Track（冻结基座 / ONTR 续训 / 探针）并行，ONTR 权重能让冻结主干从 0.1370 抬到 0.2445 |
| `DAYTIME_ONTR_REPORT_v2.md` | 五判据收口；期间修了 3 个代码 bug + 1 次 VLM 未关的配置错误 |

**为什么归档**：冻结主干这条路在 ScanNet200 1-shot 上最好只到 **0.2955**（`frozen_ontr_rep3_lovasz_s42`），
而全参数微调是 **0.4122**（`base_lovasz_s42`）。**差 11.7 点，不是调参能补的**——GFS-PCS 必须让主干可训。

**为什么还留着**：ONTR 的「零空间防坍塌」思路（把 dec2 主成分写进 dec0 的 `ker(W_b)`）本身没错，
以后如果做「必须冻结主干」的部署场景（比如端侧），这里有现成的数字。
