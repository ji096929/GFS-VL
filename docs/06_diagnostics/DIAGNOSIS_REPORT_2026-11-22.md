> 核心目的：在冻结 VLM 伪标签端与换基模两条路都被证伪后，精确锁定剩余可挖空间。

## 〇、一句话摘要

**46M PTv3 + 跨层读出在 1-shot 上已达 Base 0.6805（≈100% 全监督）与 Novel 0.3207，
跨层净增 +1.79 HM（3-seed 确定性口径，3/3 全正）；剩余可挖空间只有 Novel 距全监督的 6.83 pp，

## 一、口径声明（读所有数字前必看）

**1. `shuffle_orders` 的双重作用**
- 训练时：随机化 block↔order 配对（数据增强）
- **评估时：原本也在随机，导致同一 checkpoint 两次评估差 0.5–0.8**
- 已修：加 `and self.training`，评估完全确定（实测两次评估 0.0000 误差）

**2. 确定性评估比历史低 0.5–0.65，原因不是"抖动偏向好结果"**
`shuffle_orders=True` 时 4 个 block 随机分配 4 个序列化顺序（z / z-trans / hilbert /
hilbert-trans），等价于"随机配对的隐式集成"。关掉后锁定单一配对，所以分数略低。
**官方 GFS-VL 与 UGA 报的都是 `shuffle_orders=True`（多配对）口径。**

**3. 官方数字是五折均值**
论文原文："averaging performance across five randomly-seeded support set versions"。
种子值从代码读出为 10/20/30/40/50（`regis1..5`）。
**我们所有 ScanNet++ 数字都是单折（seed=10），不能与五折均值直接比。**

**4. `Prec` 与 `PLmIoU` 的口径差异**
`Prec` 含 `gt == -1`（143 类非评估背景）的假阳性；`PLmIoU` 排除 `gt == -1`。

**三个结论：**

**两个逐类 bug：**
- **PS 误杀**：cls 43 覆盖率 100%→11.9%（串出 4.7%→92.6%）；cls 32 100%→16.9%（串出 28.5%→100%）

**伪标签的全局质量（PL vs GT，训练集）：**

| 指标 | 值 |

| 覆盖率 < 50% 的类 | 6 个 |
| 覆盖率 > 150%（幻觉） | 14 个 |
| 串出率 > 50% | 17 个 |

## 五、拆解 2：512d VLM 特征的 Fisher 判别比

**Top-10 混淆对：均值 0.42，中位数 0.37**
```
39->12 0.36   21->12 0.12   30->48 0.31   16->28 0.08   22->20 0.50
52->17 0.65   49->20 0.38   17->53 1.18   56->51 0.43   37->40 0.18
```

**4 个漏标类 vs Base / 背景：**
```
cls 15: Base 0.43  背景 0.16
cls 30: Base 0.62  背景 0.13
cls 42: Base 0.44  背景 0.15
cls 47: Base 0.57  背景 0.22
```

**全部 < 1；漏标类与背景的 Fisher 仅 0.13–0.22（几乎完全重叠）。**

**结论：在冻结 VLM 的 512d 特征空间里这些类物理上不可分。
任何想捞回漏标类的操作必然同时灌入大量背景点。**

## 八、诊断 A：分类头尺度与决策边界（三组扫描）

**尺度实测：**
```
logits_base:  mean 5.2347  std 3.7218  max 14.000
logits_novel: mean 2.1237  std 2.4541  max 13.976
```

**S1 加性 δ（`logits[:, :12] -= δ`）：**

| δ | Base | Novel | HM |
|---|---|---|---|
| −3.00 | 0.6734 | 0.2783 | 0.3938 |
| **−0.50** | **0.6983** | **0.3332** | **0.4511** ← 最优 |
| 0.00 | 0.6934 | 0.3320 | 0.4490 |
| +3.00 | 0.5578 | 0.2758 | 0.3691 |

**S2 乘性 α（`logits[:, 12:] *= α`）：** 最优 α=0.8，HM 0.4498（vs α=1.0 的 0.4490）→ **+0.08**

**S3 Novel 内部 τ-norm：** 最优 γ=0.5、α=0.8/0.9，HM 0.4500 → **+0.10**

**判决：**

| 扫描 | 最高增益 | 门槛 | 结论 |
|---|---|---|---|
| S1 加性 δ | **+0.21** | +1.0 | ❌ |
| S2 乘性 α | +0.08 | +1.0 | ❌ |
| S3 τ-norm | +0.10 | +1.0 | ❌ |

**全部远低于 +0.5 的 kill 线。桶 A（+15.1 pp 上界）是表征级重叠，
不是决策边界/尺度失衡。所有 logit-adjustment / τ-norm / 余弦头重平衡方案全部封存。**

## 十、确定性重评：跨层增益的真值（3-seed）

**修复 `shuffle_orders` 后，同一 checkpoint 两次评估实测 0.0000 误差。**

| seed | base HM | sym HM | **Δ** |
|---|---|---|---|
| s42 | 0.4052 | 0.4359 | **+3.07** |
| s7 | 0.4241 | 0.4381 | **+1.40** |
| s13 | 0.4245 | 0.4334 | **+0.89** |
| **均值** | **0.4179** | **0.4358** | **+1.79 ± 1.14（3/3 正）** |

**口径对比：**

| 口径 | base 均值 | sym 均值 | Δ 均值 |
|---|---|---|---|
| 带抖动（`shuffle_orders=True`） | 0.4244 | 0.4410 | +1.66 |
| **确定性（`shuffle_orders=False`）** | **0.4179** | **0.4358** | **+1.79** |

**两个模型都降 0.5–0.65（丢掉多配对集成收益），但 base 降得更多，
所以配对差反而扩大。跨层增益被钉死为 `+1.79 ± 1.14`。**

**论文应报 `+1.79 ± 1.14（3 seeds, all positive）`，不能用单 seed 的 +3.07。**

## 十四、唯一剩余方向与它的问题

**剩余空间：Novel 距全监督 5.19–7.25 pp。**

**已证明这个空间：**
- 不是伪标签噪声（改 PS/AI 无效）
- 不是教师上限（学生已超教师 9.32）
- 不是分类头偏置（δ/α/τ-norm 全部 < +0.25）
- 不是骨干容量（换 46.14M Sonata-Small 反而更差）

**剩下两种可能，都未被验证：**

**1. 表征级重叠（最可能）**
桶 A（Novel→Base 47.6%）与桶 B（Novel→Novel 52.4%）都是表征重叠。
**需要训练期机制让 novel 与 base 在特征空间分离** —— 但方向未知，
且 `UGA` 在 1/5-shot + 两数据集上稳涨 +2~+3，说明它动的正是这里。

**2. 学生反哺/自训练（未测，用户提出的诊断 B）**
既然学生 val Novel（0.3207）已超教师（0.2275），
在训练集上学生是否也超 `psai`（0.4338）？如果超，
那"用学生预测替换伪标签"的迭代有物理基础。
**成本：抽 200 训练场景约 3 分钟。**

**尚未做的干净实验：**
- ScanNet++ 五折（× 4 局，约 7 小时）
- ScanNet++ 开 Lovász（预计 sym 落到 ~31.0，贴近 UGA 31.39）
- 固定种子多配对评估（同时拿到确定性与多配对收益，20–30 分钟工程）
