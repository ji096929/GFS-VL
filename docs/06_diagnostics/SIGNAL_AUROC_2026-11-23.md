# 信号判别力精确测量（v2，2026-11-23）

> **结论先行：v1 的「四信号全灭」是量化 bug 造成的假结论，全部作废。**
> 精确重测后，**熵（S1）是全场最强信号：AUROC 0.709，中位数 0.746**，
> 加权 Precision@10% 从随机基线 0.116 提到 0.283（2.44 倍）。
> **1C-a 的 +3.65 分是熵真的在提纯，机制成立。**

---

## 一、v1 的两个 bug（原结论作废）

v1 文档 `SIGNAL_AUROC_2026-11-23.md` 曾断言「四个候选过滤信号全部不合格，
最好的 S2 只有 0.616」。**这两个断言都建立在坏掉的测量工具上。**

### Bug 1：固定直方图边界，把全部信号压成 1 个 bin

v1 用 `[-3, 3]` 分 100 格（每格宽 0.06），但实测非零格数：

| 信号 | 每类非零 bin 数 | 分数真实跨度 |
|---|---|---|
| S1 负熵 | **1 / 100** | `[-2.8902, -2.8857]`（0.0045） |
| S2 文本边际 | 5–10 / 100 | 0.37 |
| S3 原型相似度 | 5–13 / 100 | 0.48 |
| S4 非 base 概率 | 17 / 100 | 1.00 |

S1 的 18 个类**每类只有 1 个 bin 有数据**。把所有正负样本塞进同一个格子里
算 AUROC，数学上恒等于 `0.500`。

**这不是「熵没有信息」，是尺子的刻度比被测对象还粗。**

### Bug 2：S3 原型提取漏了标准预处理

v1 手写 `np.load` 读原始 `coord.npy` / `color.npy`：
- `color` 是 `[0, 255]` 未归一化，跳过 `NormalizeColor`
- `coord` 未做 `CenterShift`，跳过 `GridSample`
- 相似度取「18 类 max」，而不是当前预测类 `proto[pred]`

正式训练走的是 `GFS_VL_Trainer.extract_3d_vlm_proto(regis_val_loader)`。
v1 的 S3 = 0.446（比随机还差）是这三个错误叠加的产物。

### 附带的一个自证错误

v1 还写过「1C-a 的增益来自 bug 让保留量远少于 10%」。
**日志实证：`keep=18,890,171 / (keep+drop) = 10.0%`**，1C-a 确实保留了正好
10%。没有「保留量异常」这回事。

## 二、v2 的方法

| 项 | v1 | **v2** |
|---|---|---|
| 分布表示 | 固定边界 `[-3,3]` 直方图 | **每 chunk 每类 reservoir 采样，保留原始 float32** |
| AUROC | 从 100 bin 累积 | **精确 Mann-Whitney U（ties 取 0.5）** |
| 原型 | 手写 np.load 原始数据 | **`extract_3d_vlm_proto` 标准管线** |
| 原型索引 | 18 类 max | **`proto[pred]` + 边际** |
| 纯度 | 朴素（采样比例失真） | **按真实计数加权** |

**采样设计**：`CAP=192` / chunk / class / polarity。扫描 712 chunk 后：
- 正样本采样率约 49%（95 万 / 195.6 万）
- 负样本采样率约 29%（489 万 / 1689 万）

因为少数大 chunk 里某类有几千个点会被 CAP 截断。所以**正负都要加权**，
权重取「负相对正」的比值：

```
w_neg = (n_neg_true / n_neg_sampled) / (n_pos_true / n_pos_sampled)
```

真实计数从 v1 的直方图累计取（`sum` 不受 bin 量化影响）。修正后加权总和
`18,849,474` 与真实值完全一致。

**正负样本定义**（与 v1 相同，保证可比）：

```
正 P：原场景 & GT 是 novel & pred == GT          （留住 = U2 的 0.4120）
负 N：原场景 & (GT 是 novel 但 pred 错) ∪ (GT 是背景但 pred 是 novel)
```

## 三、七个信号的结果（18 类）

| 信号 | 定义 | AUROC 均 | AUROC 中位 | 加权 P@10% 均 | P@10% 中位 |
|---|---|---|---|---|---|
| **S1 负熵** | `-H(softmax(cos_nv))` | **0.709** | **0.746** | **0.283** | 0.211 |
| S2 文本边际 | `cos_nv_max - cos_base_max` | 0.605 | 0.650 | 0.273 | 0.168 |
| S3a 预测类原型 | `cos(feat, proto[pred])` | 0.594 | 0.562 | 0.222 | 0.083 |
| S3b 原型边际 | `S3a - max_{c≠pred} cos(feat,proto_c)` | 0.623 | 0.653 | 0.240 | 0.106 |
| S4a 非 base | `1 - max_base P_3D(base\|x)` | 0.584 | 0.597 | 0.208 | 0.051 |
| **S4b 学生认可 pred** | `P_3D(pred\|x)` | **0.362** | 0.339 | 0.036 | 0.005 |
| S4c 双向净边际 | `S4b - max_base P_3D(base\|x)` | 0.558 | 0.585 | 0.139 | 0.026 |
| *随机基线* | — | 0.500 | 0.500 | **0.116** | 0.048 |

**三个关键读数**

1. **S1 最强**。它的数值动态范围只有 0.0021（熵全部挤在 `ln18` 附近），
   但在这个极窄区间里的排序**极其有效**。这解释了 1C-a 的 +3.65 分。
2. **S4b 是反向的（0.362）**。负样本的 p99 是 0.3716，正样本只有 0.0278。
   物理原因：真 novel 点（贴天花板的 smoke detector、贴墙的 whiteboard）
   会被 3D 学生判成 base，所以 `P_3D(pred)` 反而低。
3. **S4a 与 S4b 方向相反，S4c 介于两者之间**。这说明「否决 base」和
   「认可 pred」是两件不同的事，单用任一个都会偏。

### smoke detector：唯一的死亡判决

**S1 = 0.754（相当好），但 S2/S3a/S4a 全部反向（0.216/0.227/0.401）。**

所以「四信号全灭」在 smoke 上恰好看似成立，但真实情况是：
**只有熵能识别 smoke，其他三个信号在它上面是反的。**

即便如此，**S1 的 P@10% 只有 0.003**（1C-a 的 smoke IoU = 0.0045，完全对应）。
原因是结构性的：

```
smoke 正样本熵最大值 = -2.889316
全局 top-0.1% 阈值   = -2.887197
```

**smoke 的点从来没有进入全局最高分段。** 它没有「VLM 特别确定」的样本，
最多只到「稍微不那么均匀」。所以：

- 全局绝对阈值 → smoke 整类被抛弃（纯度 0%）
- 每类 top-10% → 纯度 0.27%，召回 21.8%
- 每类 top-20% → 纯度 0.31%，召回 49.3%

**无论怎么调，smoke 的纯度都 ≤ 0.35%。这是 VLM 特征决定的硬约束，
不是过滤参数问题。**

## 五、3D 否决的精确率（Exp B 的机制诊断）

`base_p > tau 且 pred 是 novel → 置 -1` 的逐阈值表现：

| tau | 误杀真点 | 清除假点 | **否决精确率** | 否决后纯度 | 真点召回 |
|---|---|---|---|---|---|
| 0.50 | 26.02% | 32.55% | 0.959 | 0.146 | 83.8% |
| 0.60 | 20.31% | 27.77% | 0.963 | 0.140 | 87.3% |
| **0.70** | **15.68%** | **23.23%** | **0.968** | 0.134 | 90.8% |
| 0.80 | 11.34% | 18.24% | 0.975 | 0.129 | 94.4% |
| 0.90 | 6.03% | 12.51% | 0.988 | 0.122 | 98.1% |
| 0.95 | 3.21% | 8.58% | 0.995 | 0.116 | 99.5% |

**否决精确率 0.968——被杀的 96.8% 确实是假点。规则本身是准的。**

0.104 提到 0.134。而且 **smoke 在 tau=0.5 时被误杀 90.6%**，tau=0.7 更甚。

## 六、真病灶：每类固定保留 10% 在数学上不可能纯

这是本轮最重要的发现。

设某类正样本率为 `r`。保留比例 `q`：
- 若 `q > r`，保留量是正样本量的 `q/r` 倍，**纯度上界 = r/q**
- smoke：r = 2.6%，q = 10% → **纯度上界 26%**
- paper：r = 1.2%，q = 10% → **纯度上界 12%**

实测加权纯度（跨 18 类）：

| 策略 | 加权纯度 | 正点召回 |
|---|---|---|
| 每类 top-10%（1C-a） | 29.41% | 27.26% |
| 全局 top-1% | 55.53% | 5.35% |
| **全局 top-2%** | **58.62%** | **11.30%** |
| 全局 top-3% | 56.73% | 16.40% |
| 全局 top-5% | 51.82% | 24.97% |
| 全局 top-10% | 42.40% | 40.86% |
| 全局 top-20% | 32.21% | 62.08% |

**全局 top-2% 的纯度是 1C-a 的 2 倍，召回只有 11.3%。**

这个坐标几乎正好压在 U2 上（纯度 100% / 召回 10.4% → HM 0.4120）。
而且**熵的绝对尺度类间差异只有 0.0004**，远小于类内动态范围 0.0021，
所以「跨类统一阈值」在数学上是合法的——这是 1C-a 没试过的做法。

**全局阈值、每类 top-k 这条轴的完整对比：**

```
                纯度      召回     smoke 纯度
每类 top-10%    29.4%    27.3%     0.27%
全局 top-2%     58.6%    11.3%     0.00%
U2（oracle）    100%     10.4%     —  → HM 0.4120
```

## 九、复现

```bash
# 原型缓存（标准管线，18/18 有效）
/data01/jh/data/step1_auroc_v2/proto_5shot.npz

# 五卡分片扫描（每片约 6 分钟）
bash /data01/jh/data/step1_auroc_v2/run_rest.sh

# 精确分析出表
python tools/analyze_signal_v2.py
# → /data01/jh/data/step1_auroc_v2/analysis.txt
```

**注意三个坑**：
1. 不要用固定直方图边界。信号动态范围可能比格宽还小。
2. 原型必须走 `extract_3d_vlm_proto`，不能手写 np.load 原始数据。
3. 加权时分母必须是「该类的总采样数」，不是「单分片的采样数」——
   否则每类会被重复计入 N_shards 次。
