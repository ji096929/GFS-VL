# 四信号判别力 AUROC（2026-11-23）

> **结论先行：四个候选过滤信号全部不合格，最好的 S2 只有 0.616，`smoke detector` 上全部低于随机。**
> 「换一个更好的过滤信号来替代熵」这条路，在 ScanNet++ 5-shot 上被数据关闭。

---

## 一、实验设置

**扫描范围**：ScanNet++ 全部 712 个训练 chunk（8 卡分片，约 3 分钟）
**口径**：`full_gt=True`（数据集的 `lookup_array` 换成 0-29 完整映射）

**正负样本定义**（在 M0 屏蔽 base 后的 18 类 Top-1 预测上）：

```
正样本 P：原场景 & GT 是 novel & pred == GT
          → 留住它们就等于 U2 的 0.4120（完美过滤上界）

负样本 N：原场景 & (GT 是 novel 但 pred 错了)      ← 错标
                 ∪ (GT 是背景但 pred 是 novel)     ← 3646 万杂物
```

**四个信号**（统一成「分数越高越可能是真点」）：

| 信号 | 定义 |
|---|---|
| S1 | `−H(softmax(cos_nv))` —— 1C-a/1C-e 用的，作为基准 |
| S2 | `cos_nv_max − cos_base_max` —— 文本边际 |
| S3 | `max_c cos(feat, proto_c)` —— 5-shot 视觉原型（本次新建，18/18 类有效） |
| S4 | `1 − max_{b<12} P_3D(b\|x)` —— 3D 学生（1A0 权重）的「非 base」概率 |

## 四、三个关键发现

### 1. S1 = 0.500 不是 bug，是「熵对这个任务完全没有信息」

cos 值挤在 `[0.43, 0.74]`，softmax 后 18 类概率都接近 1/18，**熵全部落在 `[2.85, 2.90]`**。100 个直方图 bin 覆盖 6 个单位（0.06/bin），熵的差异全被量化误差吃掉。

**推论：1C-a 的 0.3505 不是「熵筛得对」，是「bug 让保留量远少于 10%，靠量少规避了噪声」。** 它的增益来自「少给」不是「给对」。

### 2. `smoke detector` 在四个信号上全部低于随机（0.287–0.442）

**低于 0.5 意味着排序方向是反的。** 原因已经查透：smoke 的 1047 万个候选点，`cos_nv` 全挤在 `[0.43, 0.74]`，熵全等于 `ln18`。它在特征空间里是一个「均匀的球」，没有可分的结构。

**任何基于「分数高低」的信号都无法切开它。**

### 3. S2 和 S4 只在「形态规整」的类上有效

```
高 AUROC：office chair 0.86 / keyboard 0.76 / sink 0.73 / shelf 0.74 / trash can 0.71
低 AUROC：smoke 0.34 / paper 0.32 / doorframe 0.56 / windowsill 0.49
```

**这些高分类的共同点**：形态规整、和 base 有明显几何差异、在训练集里有足够实例。
**低分类的共同点**：小、稀、贴边、和某个 base 类语义接近。

## 五、对当前方法的影响

**1C-a 的 0.3505 需要重新解释**

| 原解释 | 修正后 |
|---|---|
| 屏蔽 base + 熵过滤提纯了 novel 伪标签 | **熵的 AUROC = 0.500，没有提纯能力** |
| — | 增益来自「bug 让保留量更少」，等价于「更严的随机抽样」 |

**这解释了为什么 1C-e（修 bug，正好留 10%）掉 0.85**——它比 1C-a 松了。

**「换更好的过滤信号」这条路正式关闭**

四个候选信号的 AUROC 全部 < 0.65，且最强的 S2 在小类上完全失效。**继续在这个方向投入不会有回报。**

## 六、下一步的两个方向

### 方向 A：3D Base 单向否决（不同判据）

**「否决」不需要 AUROC，只需要「高精确率」**：

```
选择：需要 AUROC > 0.8 才能挑对
否决：只要「它说 base 的时候，90% 真是 base」就够
```

**间接证据**：L1-Hybrid 的 Base 保到 0.6226（接近 PS+AI 的 0.6231），用的正是「学生判 base → 否决」。

**待验证**：S4 的精确率（而非 AUROC）。

### 方向 B：放弃过滤优化，转覆盖率

```
1C-a                    0.3505
U2（M0 完美过滤）        0.4120
U3（M1 完美过滤）        0.3613
```

**1C-a 距 U3 只差 1.08，距 U2 差 6.15。** 如果过滤已经做到头（AUROC 0.5），那 6.15 的空间只能靠「覆盖率」或「训练动力学」拿。
