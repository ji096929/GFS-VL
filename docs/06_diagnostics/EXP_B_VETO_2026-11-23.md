# Exp B：熵过滤 + 3D Base 单向否决（2026-11-23）

> **结论：方向对、机制准、但净值是负的。HM 0.3414 vs 1C-a 0.3505（−0.91）。**
> Base 涨 2.62、Novel 掉 1.26。**否决规则本身精确率高达 0.968，
> 但它系统性地误杀「贴附在 base 表面上的 novel 类」**——
> whiteboard −0.175、shelf −0.164、monitor −0.079、windowsill −0.069。

---

## 一、设置

在 1C-a（屏蔽 base + class-wise 熵 top-10%）之上，加一条**单向锁**：

```python
_base_p = softmax(seg_logits)[:, :12].max(-1).values
_veto = (base_p > 0.7) & (pred >= 12)
pred[_veto] = -1          # 只置 -1，绝不改标 novel
```

- `pl_mode = "entropy_q"`, `entropy_keep_rho = 0.1`（与 1C-a 完全相同）
- `use_3d_veto = True`, `veto_tau = 0.7`
- 3D 学生权重：`scpp_base_lovasz_k5` 的 regis1 checkpoint（与 1C-a 的骨干来源一致）
- 3 卡（GPU 0/1/2）+ `numactl --cpunodebind=0 --membind=0`
- `epoch=20`, `eval_epoch=20`（只评最后一次，与 1C-a 口径一致）
- config：`configs/scannetpp/semseg-pt-v3m1-0-gfsregistrain_k5_entq10_veto.py`
- log：`/data01/jh/data/scpp_entq10_veto.log`

### 机制

3D 学生（在 base 12 类上训练）对「贴附在 base 表面上的物体」给出高 base 概率：

- whiteboard 贴墙 → 判成 wall
- shelf 贴墙 → 判成 wall
- monitor 放桌面 → 判成 table
- windowsill 贴窗 → 判成 window
- smoke detector 贴天花 → 判成 ceiling

**这不是 bug，是几何-语义的固有耦合。** 单独一个类出错可以说是巧合，
但五个类整齐地排在「贴附」这一侧，就说明是系统性机制。

**这也解释了 smoke detector 为什么在 tau=0.5 时被误杀 90.6%**（见
`SIGNAL_AUROC_2026-11-23.md` 第五节）。

## 五、否决规则本身是准的

用 v2 的全量扫描数据算 `base_p > tau` 的精确率：

| tau | 误杀真点 | 清除假点 | 否决精确率 | 否决后纯度 | 真点召回 |
|---|---|---|---|---|---|
| 0.50 | 26.02% | 32.55% | 0.959 | 0.146 | 83.8% |
| 0.60 | 20.31% | 27.77% | 0.963 | 0.140 | 87.3% |
| **0.70** | **15.68%** | **23.23%** | **0.968** | 0.134 | 90.8% |
| 0.80 | 11.34% | 18.24% | 0.975 | 0.129 | 94.4% |
| 0.90 | 6.03% | 12.51% | 0.988 | 0.122 | 98.1% |

**否决精确率 0.968：被杀的 96.8% 确实是假点。规则是准的。**

问题在**召回**：tau=0.7 只清掉 23% 的假点。它是个高精确、低召回的过滤器。

而误杀的那 15.7% 不是均匀分布的——**集中在贴附类上**，所以对 HM 的伤害
被放大。

## 七、结论与下一步

### 三个成立的结论

1. **「单向锁」这个设计是对的**：只置 -1、绝不改标 novel，避免了 L1 学生
   的「Novel→Base 吞噬」。
2. **Base 侧已经接近饱和**：0.6302 vs U2 的 0.6393，只剩 0.91。
3. **否决精确率 0.968**，规则本身可信。

### 一个否决掉的结论

**「继续调 veto 阈值能救回来」不成立。**
tau 从 0.7 提到 0.9，误杀从 15.7% 降到 6.0%，但清除率也从 23.2% 降到 12.5%。
Base 涨幅会减半（约 +1.3），Novel 跌幅减到 1/2.6（约 −0.5），净 HM 可能
只有 +0.2。**收益太小，不值得一局 20 分钟。**

### 下一步：换轴，不换阈值

真病灶在 v2 数据里已经定位清楚：

```
每类 top-10%：纯度 29.4% / 召回 27.3%
全局 top-2%： 纯度 58.6% / 召回 11.3%
U2：          纯度 100%  / 召回 10.4%  → HM 0.4120
```

**全局 top-2% 的坐标几乎压在 U2 上。** 而且它不用 3D 学生，
因此不会踩「贴附类」这个坑。

已就绪：`configs/scannetpp/semseg-pt-v3m1-0-gfsregistrain_k5_entq_abs2.py`
（`entropy_abs_thresh = 2.888300`）。
