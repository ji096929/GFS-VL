
### 10.1 三层标尺的 oracle 三件套（核心，必须知道）

| run | HM | 构造方式 |

### 13.3 一个被推翻的错误诊断

曾有一个诊断称「`sym_xl_s42` 跑成了「只留 dec8 的单层版本」，所以 Sc200 1-shot sym 的真实增益只有 +1.23」。

**这个诊断错了。** 它看的是被覆盖的 config。权重证据：

```
epoch_3             novel_seg=(45, 192)  novel_cross=无  dec0_norm=True
epoch_12            novel_seg=(45, 192)  novel_cross=无  dec0_norm=True
regis1_model_last   novel_seg=(45, 192)  novel_cross=无  dec0_norm=True
```

三个 checkpoint 全程都是 192 维 sym。**0.4257 有效，三 seed 齐，不需要补跑，+2.17 成立。**
